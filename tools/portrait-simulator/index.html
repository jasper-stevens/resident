Resident Portrait Simulator

Local 135×240 sandbox. Connects to the same relay as resident.inanimate.tech — use your sim-… device ID with push-app.

Tap Connect, then push from your editor

idle

Quick start

  1. Run ./tools/portrait-simulator/serve.sh and open the page.
  2. Click Connect (or reconnect with an existing sim-… ID).
  3. Push an app: push.sh --device-id sim-… app.lua
  4. Or drop a .lua file onto the device.
  5. After a hard refresh, click Reload last app — no re-push needed.

Keyboard shortcuts: A = button 0, B = button 1.
